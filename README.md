# Закон Зевса · The Law of Zeus

Интерактивный разбор «Одиссеи» Кристофера Нолана (2026) через понятие **ксения** — древнегреческий закон гостеприимства, за которым стоял Зевс. Тезис: конь у Нолана не хитрость, а преступление; скитания — симметричный приговор; расправа с женихами — не месть, а восстановление закона.

Две языковые версии: русская в корне, английская в `/en/`. Некоммерческий проект.

## Что внутри

Трёхактная структура с кинематографичным погружением: две сцены, где **прокрутка управляет кадром видео** — камера идёт от общего плана коня к чёрному провалу в его брюхе, ровно повторяя тезис первого акта. Пять интерактивов: карта скитаний из двенадцати остановок, где каждая точка — тест на ксению с выбором и последствиями; тест «пережил бы ваш дом визит переодетого бога»; таймлайн, показывающий разницу между хронологией, порядком у Гомера и монтажом Нолана; сравнение бюджетов и сборов всех фильмов Нолана; квиз «Гомер или не Гомер». Все решения сходятся в один счётчик — «весы Зевса» в углу экрана.

## Технически

Статический сайт без зависимостей и сборщиков. Обе версии генерируются из одного источника скриптом `tools/build.py`, шрифты вшиты в HTML, интерактивы — на чистом JS.

Мобильный опыт полноценный: PWA с манифестом и service worker (устанавливается на iOS и Android, работает офлайн), учёт `safe-area-inset` под вырезы, единицы `svh` вместо `vh`, тач-обработчики везде, где на десктопе используется наведение, цели нажатия не меньше 44 px, тактильный отклик через Vibration API, системное «Поделиться» через Web Share API. Уважается `prefers-reduced-motion`, экономия трафика через `saveData`.

### Сборка

```bash
python3 tools/build.py     # → index.html, en/index.html, manifest, sw.js
```

Текст правится в `tools/content.py`, данные интерактивов — в `tools/data.py`, вёрстка — в `tools/tpl_*.html`.

## Публикация на GitHub Pages

Репозиторий готов к деплою: workflow лежит в `.github/workflows/pages.yml`.

```bash
git remote add origin https://github.com/<логин>/odyssey-nolan-review.git
git branch -M main
git push -u origin main
```

Дальше в настройках репозитория: **Settings → Pages → Source → GitHub Actions**. Через минуту страница поднимется на `https://<логин>.github.io/odyssey-nolan-review/`.

Видео в `assets/` весит около 11 МБ — это в пределах лимитов Pages, Git LFS не нужен.

## Права

Независимый некоммерческий разбор, не связанный с Universal Pictures и Syncopy. Изображения и видео созданы средствами ИИ специально для этого материала; кадры фильма и постеры не используются. Если в `assets/` положены фрагменты официального трейлера, они цитируются короткими отрывками с указанием правообладателя — стандартная практика критического разбора. Цитаты из текстов приведены в объёме, необходимом для анализа, со ссылками на источники.
